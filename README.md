
# 🎂 Doce Sabor

Bem-vindo ao projeto **Doce Sabor**!

Este projeto tem como objetivo criar um site para uma confeitaria, utilizando HTML e CSS.

## 🍰 Sobre o projeto

O site apresenta a confeitaria e suas principais funcionalidades, como cardápio, perguntas frequentes, localização da loja e formulário de encomendas.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
